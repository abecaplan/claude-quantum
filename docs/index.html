Entanglement, and Einstein's objection

A qubit is a physical system with two measurable states, |0⟩ and |1⟩. Quantum mechanics allows two qubits to be prepared in the entangled state |Φ⁺⟩ = (|00⟩ + |11⟩)/√2, which has a strange property: the pair is in a perfectly definite state, but neither qubit individually is. Measure both the same way and you get the same answer every time — both 0 or both 1, at random.

Correlation alone isn't spooky: two sealed envelopes holding matching letters do the same, because the answers were fixed all along. Einstein insisted something like that had to be the truth — that particles carry hidden "instruction lists" fixing every outcome in advance (realism), and that nothing done to one particle can instantly affect the other (locality). His jab about "spooky action at a distance" and the 1935 Einstein–Podolsky–Rosen paper argued quantum mechanics must be incomplete — to be finished off by such local hidden variables. For thirty years this was treated as untestable philosophy.

Bell's theorem turns it into arithmetic

In 1964 John Bell proved it is testable. Alice and Bob each hold one qubit. Alice measures with setting a or a′, Bob with b or b′; every measurement returns ±1. Write E(a,b) for the average product of their outcomes, and combine four correlations (Clauser–Horne–Shimony–Holt, 1969):

S = E(a,b) − E(a,b′) + E(a′,b) + E(a′,b′)

If outcomes are fixed in advance by any instruction lists whatsoever, then in every run the four predetermined ±1 values satisfy a(b−b′) + a′(b+b′) = ±2 — one parenthesis is always zero, the other ±2. Averaging over runs:

|S| ≤ 2  for every local hidden-variable theory while quantum mechanics, with measurement bases tilted 45° apart, reaches |S| = 2√2 ≈ 2.828 — the Tsirelson bound

That gap, between 2 and 2.828, is where metaphysics gets settled by counting. Measure |S| > 2 and every possible local hidden-variable explanation is ruled out at once — no matter its mechanism.

What this experiment did

Prepare the Bell state on two superconducting qubits (a Hadamard, then a CNOT — circuit depth 8 after compilation to native gates). Sweep Alice's basis with an RY(θ) rotation through 15 angles from 0 to 2π — tracing the entire correlation curve, a far stricter comparison with theory than a single number. Measure the four correlators ⟨ZZ⟩, ⟨ZX⟩, ⟨XZ⟩, ⟨XX⟩ at each angle, 4096 shots apiece, and combine them into the two witnesses plotted above.

The prediction, computed exactly by independent simulation: both witnesses trace sinusoids touching 2√2 at odd multiples of π/4, with S₁(0) = 2 — sitting exactly on the classical boundary, where the bases align and the envelope story still suffices. The measured curves match point for point, and the peak lands at |S| = 3.003 ± 0.029: thirty-four standard deviations beyond anything instruction lists can produce.

⚖️ Why 3.003 beats the "quantum limit"

It doesn't. The run used IBM's readout-error mitigation, which corrects the ~1.3% chance of misreading each qubit by extrapolating what a perfect readout would have seen — and extrapolation overshoots. Several mitigated points land slightly past 2.828; the raw data would sit at or below it. A known artifact, documented in the run log, slated for direct study in a future phase.

🔬 What this does — and doesn't — prove

The qubits sit a fraction of a millimetre apart, so light-speed signals could cross between them mid-measurement: the locality loophole is wide open. Loophole-free tests took heroic engineering — diamond spins 1.3 km apart (Delft 2015), a 30 m cryogenic link for superconducting qubits (ETH 2023). What this run demonstrates is different but real: a public quantum computer produces, on demand, the correlations local realism forbids — and an AI can now build the entire experimental pipeline around that fact.

Context

Fifty-four years of Bell tests

The 2022 Nobel Prize in Physics went to Clauser, Aspect, and Zeilinger "for experiments with entangled photons, establishing the violation of Bell inequalities and pioneering quantum information science." This project is a direct descendant — same inequality, same question.

1972 — Freedman & Clauser, Berkeley
First Bell test ever: a calcium atomic beam and hand-built polarizers. Violation by ~6σ after 200 hours of data collection.
1982 — Aspect, Grangier & Roger, Orsay
S = 2.697 ± 0.015 (~40σ); months later, measurement settings switched while the photons were already in flight.
2015 — the loophole-free year
Delft: electron spins in diamonds 1.3 km apart, S = 2.42 ± 0.20 — the first test closing the major loopholes at once. NIST and Vienna followed within months with photons (p ≪ 10⁻⁶).
2022 — the Nobel Prize
Physics prize to Clauser, Aspect, Zeilinger for establishing Bell violations experimentally and founding quantum information science.
2023 — Storz et al., ETH Zurich
Loophole-free violation with superconducting circuits — this hardware family — over a 30 m cryogenic link: S = 2.0747 ± 0.0033.
2026 — this project
|S| = 3.003 ± 0.029 (mitigated), 34.8σ, on a public 156-qubit processor. 79 seconds of free QPU time. Every line of code written by an AI.

The comparison is not of scientific weight — the earlier entries closed loopholes and settled a foundational question; this project inherits their answer. The comparison is of access: what once required a national laboratory now requires a free account and a well-checked script.

Methodology

Vibe-coded, but gated

The entire codebase — circuit construction, hardware orchestration, analysis, verification, plotting, and the documentation you are reading — was written by Claude through conversational direction. No code was written by hand. Vibe coding has a reputation for producing software that looks right rather than is right; for an experiment that spends a nonrefundable hardware budget and makes a checkable scientific claim, looking right is worthless. So everything ran under strict protocols, set before any hardware was touched:

  1. Physics first, SDK second The circuit and observables were fixed by exact mathematics and treated as immutable; every quantum-SDK call was treated as provisional. Correctness lives in the physics check, never in "the API call didn't error."
  2. A hard simulator gate Hardware execution stayed locked until a noiseless simulation reproduced the theory curve — peak |S| within [2.80, 2.85] on the run grid, peak at a correct lobe, S₁(0) ≈ 2. Gate fails → the script exits, hardware stays locked.
  3. Independent verification A separate verifier re-derives the expected physics from scratch in pure NumPy — its own gate matrices, its own conventions — and checks the recorded results against that independent derivation, trusting nothing from the experiment code.
  4. Budget guards in code Shot counts capped in code (the script refuses more), the sweep trimmed to 15 points, single-job execution — no bug could burn the 10-minute monthly quota. Actual spend: 79 s.
  5. Credential hygiene No token ever appears in code or committed files. Credentials come from the environment or a locally saved account only.
  6. Results as a contract Every run writes one schema-stable JSON; analysis and plotting read only the JSON, never the live run. The recorded artifact is the experiment.
  7. Honest reporting The mitigation overshoot past 2.828 is documented as an artifact — not spun as a discovery.

The interesting methodological claim is not "an AI can write Qiskit code." It is that the gating discipline — not the code generation — is what made the result trustworthy, and that the discipline itself is specifiable in natural language.

Reproduce it

The simulation path is free and offline

pip install -r requirements.txt
python experiments/exp1_chsh.py --sim --out results/chsh_sim.json   # the correctness gate
python analysis/verify.py results/chsh_sim.json                     # independent check

To rerun on hardware: create a free IBM Quantum account (Open Plan, 10 min QPU/month), save credentials locally, and — only after the gate passes — run python experiments/exp1_chsh.py --hardware (~80 s of QPU time). Full source, data, and run log: github.com/abecaplan/claude-quantum.
